Part A: derivations from memory (write them, then check)

Close the lessons. Derive, then open to compare.
Spring stress with Ks, then with the Wahl factor K.
Cut the coil: torque PD/2 and shear P. τ₁ = 8PD/πd³, τ₂ = 4P/πd² = τ₁(0.5/C), so τ = Ks(8PD/πd³) with Ks = 1 + 0.5/C. Add curvature: K = (4C − 1)/(4C − 4) + 0.615/C. See .
Spring deflection δ = 8PD³N/Gd⁴.
Uncoil: l = πDN, θ = (PD/2)l/GJ = 16PD²N/Gd⁴, δ = θD/2. See .
Concentric springs: same C, and load ∝ d².
Equal stress: P₁D₁/d₁³ = P₂D₂/d₂³. Equal deflection plus equal solid length gives P₁D₁³/d₁⁵ = P₂D₂³/d₂⁵. Dividing: C₁ = C₂, so P₁/P₂ = d₁²/d₂². With 2c = d₁ − d₂: d₁/d₂ = C/(C − 2). See .
Spring fatigue: Eq. 10.22 and the (fs) formula.
Similar triangles under the design line: τa/(Ssy/fs − τm) = ½S′se/(Ssy − ½S′se), with Ks on τm and K on τa. See .
Open-coiled spring: δ and τmax.
T = WR cos α, M = WR sin α, L = 2πRn/cos α. U = (T²/2GJ + M²/2EI)L, so δ = (64WR³n/d⁴cos α)(cos²α/G + 2sin²α/E). τmax = 16WR/πd³ (independent of α) and σ₁ = (16WR/πd³)(1 + sin α). See .
Leaf spring: the 12/18 stresses, and the nip.
Triangle plate: σg = 6PgL/ngbt² and δg = 6PgL³/Engbt³. Rectangle: σf = 6PfL/nfbt² and δf = 4PfL³/Enfbt³. Equal δ gives σg = 12PL/(3nf + 2ng)bt² and σf = 18PL/(…). Nip C = 2PL³/Enbt³ and σ = 6PL/nbt². See .
Law of gearing; minimum teeth 2/sin²α; compact two-stage box.
ω₁/ω₂ = O₂P/O₁P, so P must be fixed. The interference point is r sin²α below the pitch line, and m ≤ (mz/2)sin²α gives z ≥ 2/sin²α. For the box, a ∝ 2 + i₁ + i/i₁, which is minimum at i₁ = √i. See .
Lewis equation and Buckingham wear strength.
σ = 6Pth/bt² at the parabola's tangent section, so Pt = mbσY with Y = t²/6hm. Hertz with r = d′sin α/2 gives Sw = bQd′pK, Q = 2zg/(zg + zp), K = σc² sin α cos α(1/E₁ + 1/E₂)/1.4. See and .
Helical z′ = z/cos³ψ, and the bevel factor (1 − b/A₀).
The normal section is an ellipse with r′ = a²/b = d/2cos²ψ, so z′ = 2πr′/pn = z/cos³ψ. For the bevel, integrate mxσY dx × rx from A₀ − b to A₀, divide by R, and drop the b²/3A₀² term. See and .

Part B: name the method (GATE-style)

A gear question says "the gears are machined to Grade 6". That tells you to:

  1. use Cv = 6/(6 + v) for hobbed gears
  2. find Pd by Buckingham with Table 17.8 errors
  3. increase the module by one standard step
  4. take the service factor as 1.25 from Table 17.4
The grade sets the tolerance e = A + Bφ μm, which feeds Buckingham's dynamic load (§17.19).

"The leaves are pre-stressed so that all leaves have the same stress at maximum load." The design equation is:

  1. σ = 12PL/(3nf + 2ng)bt²
  2. σ = 18PL/(3nf + 2ng)bt²
  3. σ = 6PL/ngbt² for the graduated leaves
  4. σ = 6PL/nbt² with n the total leaves
Nipping makes Pg/Pf = ng/nf, so every leaf carries 6PL/nbt² (Eq. 10.41).

A spring balance has "a scale of 100 mm divided into 50 divisions of 0.5 kg each". This directly fixes the spring's:

  1. stiffness, as force per division length
  2. wire diameter, through the Wahl factor
  3. spring index, through the scale ratio
  4. solid length, as the scale length
k = (0.5 × 9.81 N)/(2 mm) = 2.4525 N/mm. N then follows from k = Gd⁴/8D³N (Ex. 10.12).

Two shafts intersect at 90° and the speed must be reduced 1.5:1 with a positive drive. The natural choice is:

  1. a crossed helical gear pair
  2. a worm and worm wheel
  3. a straight bevel gear pair
  4. a herringbone gear pair
Intersecting shafts call for bevel gears, at 1:1 up to 3:1. A worm suits non-intersecting shafts and large ratios. Herringbone gears need parallel shafts.

Part C: Bhandari Examples, interleaved

Ex. 17.12 (): two-stage spur reducer, 10 kW at 1440 rpm → about 180 rpm, 18/51 teeth per stage, 45C8 (Sut = 700) at 340 BHN, Grade 6, Cs = 1.5. Bhandari designs the second stage with m = 6, b = 60 mm. Factor of safety in bending, with Buckingham?

The second stage carries more torque: nB = 508.24 rpm, so Mt = 187 891 N·mm. d₃′ = 108, so Pt = 3479.5 N, and v = 2.874 m/s. Sb = 6(60)(700/3)(0.308) = 25 872 N. e = 13.417 + 14.535 = 27.95 μm. Pd = 6473.8 N and Peff = 1.5(3479.5) + 6473.8 = 11 693 N. (fs) = 2.21. Pitting: Q = 1.478, Sw = 17 718 N, (fs) = 1.52.

Ex. 10.10 (): a shock-absorbing spring has an initial compression of 30 mm and is compressed a further 50 mm while absorbing 250 J. Spring stiffness?

P₁ = 30k and P₂ = 80k. Energy = average force × travel = 55k × 50 = 250 × 10³ N·mm, so k = 90.91 N/mm. Pmax = 7272.7 N. With C = 6 and τ = 450: d = 17.59 → 18, D = 108, N = 9.32 → 10, free length 325 mm.

Ex. 19.3 (): differential train. 10 kW at 500 rpm enters on bevel A (mid-face diameter 250). A drives B (125). C (250) is on B's shaft and drives D (500). Spur E (250) is on D's shaft and drives F (350) on output shaft 2. Torque on output shaft 2?

Mt = 190 986 N·mm. (Pt)AB = 190 986/125 = 1527.9 N. On shaft B–C: 1527.9(62.5) = (Pt)CD(125), so (Pt)CD = 763.9 N. On shaft D–E: 763.9(250) = (Pt)EF(125), so (Pt)EF = 1527.9 N. Shaft 2: 1527.9 × 175 = 267 381 N·mm. Shaft 1 carries (Pt)AB(125) + (Pt)CD(250) = 381 972 N·mm.

Ex. 10.4 (): valve spring, 150 N closed and 300 N open, length 35 mm closed and 30 mm open, inside diameter at least 20 mm, Sut = 1370, τ = 0.3Sut. Bhandari ends with d = 4, D = 24, N = 7. Deflection at the maximum force?

First trial with K = 1: d³/(20 + d) = 8(300)/π(411) = 1.859, so d is between 3 and 4. Take 4 to allow for K. Check: C = 6, τ = 1.2525 × 8(300)(24)/π(64) = 358.8 < 411 ✓. N: 5 = 8(150)(24)³N/(81 370 × 4⁴), so N = 6.28 → 7. δmax = 8(300)(24)³(7)/(81 370 × 256) = 11.15 mm. Gap 15% = 1.67 mm, solid 36 mm, free length 50 mm, pitch 6.25 mm.

Ex. 18.3 (): double-reduction helical box, 10 kW at 720 rpm into pinion A (20 teeth). A–B: 20/50 teeth, mn = 3, ψ = 30°. C–D: 20/60 teeth, mn = 5, ψ = 25°. B and C are on shaft 2, and their thrusts act in opposite directions. Bearing B2 takes all the thrust. Thrust on B2?

dA = 69.28 mm, so (Pt)AB = 2(132 629)/69.28 = 3828.8 N and (Pa)AB = 3828.8 tan 30° = 2210.5 N. Shaft 2 torque = 3828.8(173.21/2) = 331 591 N·mm. dC = 110.34, so (Pt)CD = 6010.4 N and (Pa)CD = 6010.4 tan 25° = 2802.7 N. Net thrust on B2 = 2802.7 − 2210.5 = 592.1 N. That is why designers choose the helix hands so the thrusts on an intermediate shaft partly cancel.

Ex. 10.18 (): concentric springs with the same free length carry 2000 N. Inner spring: d = 8, D = 64, N = 12. Outer spring: d = 10, D = 80, N = 8. G = 81 370. Maximum deflection?

Equal deflection: PiDi³Ni/di⁴ = PoDo³No/do⁴, so Po = 1.875Pi. With a 2000 N total: Po = 1304.35 N and Pi = 695.65 N. δ = 8(1304.35)(80)³(8)/(81 370 × 10⁴) = 52.53 mm. Stresses (C = 8, K = 1.184): 314.6 (outer) and 262.2 (inner) N/mm². These springs are not designed for equal stress, so P ∝ d² does not apply.

Ex. 10.3 (): Pmax = 7.5 kN, D = 150 mm (fixed by space), k = 75 N/mm, Sut = 1250, τ = 0.3Sut. Wire diameter before rounding?

τ = 375 and d = 150/C: 375 = K·8PC³/π(150)², so KC³ = 441.8. C = 7.1 gives 432.9 and C = 7.2 gives 450.3, so take C = 7.2. d = 150/7.2 = 20.83 → 21 mm. N from k = Gd⁴/8D³N: N = 7.81 → 8.

Ex. 10.19 (): the outer spring is 15 mm longer than the inner one. Inner: d = 5, D = 30, N = 8. Outer: d = 6, D = 36, N = 10. G = 81 370 and total load 1000 N. Force carried by the outer spring?

ki = 29.43 and ko = 28.25 N/mm. The outer spring alone takes the first 15 mm: 28.25 × 15 = 423.75 N. The remaining 576.25 N goes to both springs in parallel: x = 576.25/57.68 = 9.99 mm. Po = 28.25(24.99) = 706 N and Pi = 294 N. Stresses 375.3 and 225.1 N/mm². This stepped rate is the "variable force–deflection" spring used in governors.
