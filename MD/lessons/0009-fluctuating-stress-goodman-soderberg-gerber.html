Fluctuating stress: Soderberg, Goodman and Gerber criteria

About 30 minutes · Bhandari §5.12–5.14

Your win: when a stress has both a mean and an alternating part, you can locate the limiting point on the modified Goodman diagram and size the part. You can also give the factor of safety by all three criteria. These are question bank Q18–Q21.
Warm-up (Lessons 6–8)
σm and σa from σmax and σmin?
\(\sigma_m = \frac12(\sigma_{max}+\sigma_{min})\), \(\sigma_a = \frac12(\sigma_{max}-\sigma_{min})\)

(10³ cycles, 0.9 Sut)

1. Three borderlines between safe and unsafe

Plot mean stress σm horizontally and amplitude σa vertically. Pure reversal (σm = 0) fails at Se. Pure static load (σa = 0) fails at Sut or Syt. Between them ():

Fatigue failure criteria (Eqs 5.36, 5.37, 5.46) \[ \text{Soderberg: } \frac{S_m}{S_{yt}} + \frac{S_a}{S_e} = 1 \qquad \text{Goodman: } \frac{S_m}{S_{ut}} + \frac{S_a}{S_e} = 1 \qquad \text{Gerber: } \frac{S_a}{S_e} + \left(\frac{S_m}{S_{ut}}\right)^2 = 1 \]
  • Gerber (parabola) runs through the middle of the test data: most accurate, least conservative.
  • Goodman (straight line to Sut) sits just below the data. It's the most used: safe and simple, and a rough sketch is enough ().
  • Soderberg (straight line to Syt) is the most conservative, so no separate yield check is needed.

With a factor of safety: replace Sa, Sm by n·σa, n·σm. For example, Goodman becomes \(\frac{1}{n} = \frac{\sigma_a}{S_e} + \frac{\sigma_m}{S_{ut}}\).

Preloaded with Example 5.17 (σ varies 40 → 100 N/mm²). Push σm up towards 300 and watch the yield line take over from the Goodman line.

2. Bhandari's modified Goodman diagram

A point with large σm and small σa can sit inside the Goodman line yet yield on the first cycle. So Bhandari adds the yield line joining Syt on both axes. The safe region OABC is bounded by the Goodman line from Se to B, then the yield line from B to Syt ().

Procedure for axial or bending stress
  1. Load line through the origin: \(\tan\theta = \dfrac{\sigma_a}{\sigma_m} = \dfrac{P_a}{P_m} = \dfrac{(M_b)_a}{(M_b)_m}\). You don't need d to find it.
  2. Intersect with the Goodman line: \(S_a = \dfrac{1}{\frac{1}{S_e} + \frac{1}{S_{ut}\tan\theta}}\), \(S_m = S_a/\tan\theta\). Check \(S_a + S_m \le S_{yt}\). If not, the yield line governs.
  3. Design: \(\sigma_a = \dfrac{S_a}{(fs)}\) (or \(\sigma_m = S_m/(fs)\)) and solve for the size.
Torsional shear: mean stress does not matter (Eqs 5.42–5.45)

The safe line is horizontal at Sse until it meets the yield line. So: \(\tau_a = \dfrac{S_{se}}{(fs)}\) for fatigue, and \(\tau_{max} = \tau_m + \tau_a = \dfrac{S_{sy}}{(fs)}\) for yielding.

3. Worked example (Bhandari Ex. 5.12, question bank Q18)

Example 5.12 (). A cantilever of cold-drawn steel 40C8 (Sut = 600, Syt = 380 N/mm²). The end force varies from −50 N to +150 N, acting 100 mm from the fillet section. Reliability 90%, (fs) = 2, q = 0.9, Kt = 1.44, Ka = 0.77, Kb = 0.85. Find d at the fillet.
  1. \(K_f = 1 + 0.9(0.44) = 1.396\); \(S_e = 0.77(0.85)(0.897)(1/1.396)(300) = 126.11\) N/mm².
  2. \((M_b)_{max} = 15\,000\), \((M_b)_{min} = -5000\) N·mm. So \((M_b)_m = 5000\), \((M_b)_a = 10\,000\), and \(\tan\theta = 2\).
  3. Goodman ∩ load line: \(\frac{S_a}{126.11} + \frac{S_a/2}{600} = 1 \Rightarrow S_a = 114.12\), \(S_m = 57.06\) N/mm². Their sum, 171 < 380, so the point is on the Goodman part.
  4. \(\dfrac{32(10\,000)}{\pi d^3} = \dfrac{114.12}{2} \Rightarrow d = 12.13\) mm.

4. Practice

Bhandari Ex. 5.17A part's stress varies from 40 to 100 N/mm². Corrected Se = 270, Sut = 600, Syt = 450 N/mm². Find the factor of safety by each criterion.

(a) Goodman

σm = 70, σa = 30. \(\frac1n = \frac{30}{270} + \frac{70}{600}\Rightarrow n = 4.39\).

(b) Soderberg

\(\frac1n = \frac{30}{270} + \frac{70}{450}\Rightarrow n = 3.75\).

(c) Gerber

\(\frac{30n}{270} + \left(\frac{70n}{600}\right)^2 = 1\Rightarrow n^2 + 8.16n - 73.47 = 0 \Rightarrow n = 5.41\). Against static yielding: 450/100 = 4.5.

Question bank Q19 (Ex. 5.13, ): a shaft of cold-drawn 27Mn2 (Sut = 500, Syt = 300) carries a torque varying from −100 to +400 N·m. (fs) = 2, reliability 90%, Ka = 0.79, Kb = 0.85, no stress concentration, distortion energy theory. Find d.

\(S_{se} = 0.577(150.58) = 86.88\) N/mm². \((M_t)_a = 250\) N·m. For torsion the limit is \(S_{sa} = S_{se}\), whatever the mean.

\(\frac{16(250\times10^3)}{\pi d^3} = \frac{86.88}{2}\Rightarrow d = 30.83\) mm. Yield check: \(\tau_{max} = 16(400\times10^3)/\pi(30.83)^3 = 69.5 \le 173.1/2 = 86.6\). OK.

Question bank Q20 (Ex. 5.14): a spherical vessel, 500 mm inner diameter, cold-drawn 20C8 (Sut = 440, Syt = 242). Pressure varies 0 → 6 N/mm². Reliability 50%, (fs) = 3.5, Kb = 0.85, Ka = 0.82, infinite life. Find t. (Sphere: σ = pD/4t.)

\(S_e = 0.82(0.85)(1)(220) = 153.34\). σmax = 750/t and σmin = 0, so σa = σm = 375/t and tan θ = 1.

Goodman: \(S_a = 1/(1/153.34 + 1/440) = 113.71\). \(375/t = 113.71/3.5 \Rightarrow t = 11.54\) mm.

Question bank Q21 (Ex. 5.15, finite life): a 10 mm cantilever wire of stainless steel (Sut = 860, Syt = 690), 500 mm long. The end force varies 75 → 150 N. Ka = 0.72, Kb = 0.85, reliability 50%. Find the life.

\(S_e = 0.72(0.85)(430) = 263.16\). σm = 32(56 250)/π(10)³ = 572.96 and σa = 190.99. The point lies outside the Goodman line, so life is finite.

Line from (Sut, 0) through the point to the σa axis: \(S_f = \frac{\sigma_a S_{ut}}{S_{ut}-\sigma_m} = 572.2\) N/mm².

S–N: \(\log N = 3 + \frac{3(\log774 - \log572.2)}{\log774 - \log263.16} = 3.8395\Rightarrow N \approx 6910\) cycles.

Which criterion needs no separate check against yielding?

  1. Goodman, because it is a straight line
  2. Soderberg, because it ends at Syt
  3. Gerber, because it fits the test data
  4. Modified Goodman, because it is curved
The Soderberg line joins Se to Syt and lies entirely inside the yield line, so any point safe by Soderberg is safe against first-cycle yielding.

For a shaft under fluctuating torsion only, what does Bhandari's modified Goodman diagram say?

  1. The limit falls linearly as mean stress rises
  2. The limit follows the Gerber parabola in shear
  3. Mean stress has no effect until yielding starts
  4. Only the maximum stress should be considered
For torsional shear, line AB is horizontal at Sse up to the yield line (Fig. 5.41). So you design with τa = Sse/(fs) and check τmax ≤ Ssy/(fs).

Why can you find tan θ before you know the diameter?

  1. σa/σm equals the ratio of the load amplitudes
  2. The diameter is always assumed to be 50 mm
  3. tan θ depends only on Sut and Se
  4. The Goodman line passes through the origin
Both stresses share the same section property, so it cancels: σa/σm = Pa/Pm = (Mb)a/(Mb)m (Eqs 5.39, 5.40).

Exam traps

  • Applying the Goodman line to torsion. For shear, τa = Sse/(fs).
  • Forgetting the yield check (Sa + Sm ≤ Syt).
  • Mixing up which strength goes on which axis: Se on the σa axis, Sut or Syt on the σm axis.
  • Not sketching the diagram. Most examiners give marks for the labelled sketch.
