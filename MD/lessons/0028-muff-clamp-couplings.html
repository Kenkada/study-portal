1. Couplings: what and which

A coupling permanently joins two rotating shafts (motor to pump, motor to gearbox). A clutch, by contrast, can connect and disconnect at will ().

Shaft axesCoupling
Collinear, accurately aligned, no shockRigid: muff, clamp, flange
Collinear with slight misalignment, shockFlexible: bushed-pin (about 0.5 mm lateral/axial, 1.5° angular), multiflex
Parallel, small offsetOldham coupling
IntersectingHooke's (universal) joint

Requirements of a good coupling: transmit the full torque, keep the shafts aligned, be easy to assemble and dismantle, and have no projecting parts (or guard them).

2. Muff (sleeve, box) coupling

A cast-iron sleeve keyed over both shaft ends. Torque path: shaft → key → sleeve → key → shaft. For: simplest (2 parts), smooth outside, compact, cheap. Against: hard to assemble (shift the sleeve or the shafts), needs accurate alignment, no shock absorption, long. Used up to about 70 mm shafts ().

Muff coupling procedure (§9.18)

d from \(\tau = 16M_t/\pi d^3\) → sleeve \(D = 2d + 13\) mm, \(L = 3.5d\) → check sleeve as a hollow shaft \(\tau = \frac{16M_tD}{\pi(D^4 - d^4)}\) → key from Table 9.3, length L/2 in each shaft, check τ and σc.

3. Clamp (split-muff, compression) coupling: derivation

The sleeve is split in two along the shaft axis and clamped by bolts (4 or 8, always multiples of 4). Torque goes by friction plus a key, but each is designed for the full torque. Easy to fit without moving the shafts, but hard to balance (not for high speed), unsuitable for shock, needs a guard. Used for line shafts (now obsolete) ().

Derive the bolt force needed for a clamp coupling with n bolts, friction coefficient f, shaft diameter d (Eq. 9.40).
  1. Half the bolts (n/2) clamp each shaft. Each bolt pulls with P₁, so the clamping force on one shaft is \(N = P_1\,\dfrac{n}{2}\).
  2. Each sleeve half presses on the shaft with N (upper and lower halves). The friction on each half is fN, acting at radius d/2.
  3. Friction torque: \(M_t = 2\,(fN)\,\dfrac{d}{2} = fNd = f\,d\,P_1\,\dfrac{n}{2}\).
  4. So \(\boxed{P_1 = \dfrac{2M_t}{f\,d\,n}}\), and the bolt core size from \(P_1 = \dfrac{\pi}{4}d_1^2\sigma_t\). f ≈ 0.3. Empirical alternative: d₁ = 0.2d + 10 (d < 55 mm), 0.15d + 15 (d > 55 mm); sleeve D = 2.5d, L = 3.5d.

4. Practice (Bhandari Examples)

Ex. 9.18 (): muff coupling25 kW at 360 rpm. Shafts and key 30C8 (Syt = Syc = 400), (fs) = 4; sleeve FG 200, (fs) = 6 on ultimate (Ssu = 0.5Sut).

(a) Shaft diameter before rounding.

Mt = 663 146 N·mm; τ = 50 ⇒ d = 40.73, so 45 mm.

(b) With d = 45, D = 105, L = 160 mm, find the shear stress in the sleeve.

J = π(105⁴ − 45⁴)/32 = 11.53 × 10⁶ mm⁴; τ = 663 146 × 52.5/J = 3.02 < 16.67 ✓.

(c) Key 14 × 9 × 80 (L/2): crushing stress?

σc = 4Mt/(dhl) = 4(663 146)/(45 × 9 × 80) = 81.87 < 100 ✓; τ = 26.32 < 50 ✓.

Ex. 9.19 (): clamp coupling50 kW at 120 rpm; 30C8 (Syt = 400, Syc = 1.5Syt), (fs) = 5; 8 bolts; f = 0.3.

(a) Shaft diameter.

Mt = 3 978 874 N·mm; τ = 40 ⇒ d = 79.72, so 80 mm; D = 200, L = 280 mm.

(b) Bolt core diameter on the friction basis.

P₁ = 2Mt/(fdn) = 2(3 978 874)/(0.3 × 80 × 8) = 41 447 N. d₁ = √(4P₁/(π × 80)) = 25.68, so 26 mm (empirical: 0.15(80) + 15 = 27 mm). Key 22 × 14 × 140: τ = 32.3, σc = 101.5 ✓.

5. GATE corner

How is torque transmitted in a muff coupling, compared with a clamp coupling?

  1. Both transmit torque only by friction
  2. Muff by friction; clamp only by key shear
  3. Muff by key shear; clamp by friction and key
  4. Both transmit torque only through bolt shear
Muff: key shear alone. Clamp: friction from the bolt clamping plus the key, each designed for full torque ().

Doubling the number of clamping bolts (same bolt size) in a clamp coupling changes its friction torque capacity by a factor of:

  1. 1, since only the key carries torque
  2. 2, since torque is proportional to n
  3. 4, since torque is proportional to n²
  4. √2, since bolts act in pairs
Mt = f d P₁ n/2, which is linear in n.

Exam traps

  • Clamp coupling: only n/2 bolts act on each shaft.
