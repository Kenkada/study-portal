Design of the knuckle joint

About 25 minutes · Bhandari §4.11–4.12

Your win: you can design a knuckle joint: rod, pin (shear and bending), eye and fork, with every stress checked. You'll also be able to finish the knuckle half of Tutorial Q6.
Warm-up (Lesson 12)
Which two calculations give the cotter width b?
Double shear (P = 2btτ) and bending of a loose cotter. Take the larger.
Why can't a cotter joint join rotating shafts?
It is designed for axial load only; torque needs a coupling.

1. What it is

A knuckle (forked-pin) joint connects two rods whose axes coincide or intersect in one plane. It carries axial tension and allows limited angular movement about the pin (). Rod B ends in an eye, rod A in a fork (double eye). A pin through both is held by a split pin. Uses: roof-truss tie bars, suspension-bridge links, valve gear, lever fulcrums, bicycle chain links. Advantages: simple, few parts, quick to assemble.

2. The failure equations

FailureEquation (Bhandari Eqs 4.26)
Tension in rod\(P = \frac{\pi}{4}D^2\sigma_t\); enlarged D₁ = 1.1D
Double shear of pin\(P = 2\cdot\frac{\pi}{4}d^2\tau\Rightarrow d = \sqrt{2P/\pi\tau}\)
Bending of a loose pin\(\sigma_b = \dfrac{32\,(P/2)\left[\frac{b}{4}+\frac{a}{3}\right]}{\pi d^3}\) (uniform load in the eye, triangular in the fork)
Crushing of pin in eye / in fork\(P = b\,d\,\sigma_c\); \(P = 2a\,d\,\sigma_c\)
Tension in eye / fork\(P = b(d_0-d)\sigma_t\); \(P = 2a(d_0-d)\sigma_t\)
Shear of eye / fork\(P = b(d_0-d)\tau\); \(P = 2a(d_0-d)\tau\)
Standard proportions

d = D (first guess) · d₀ = 2d · d₁ = 1.5d · a = 0.75D · b = 1.25D · D₁ = 1.1D · gap x ≈ 10 mm ()

Procedure (§4.12)

D → D₁ → a, b → pin d (larger of shear and bending) → d₀, d₁ → check eye (tension, crushing, shear) → check fork (tension, crushing, shear).

3. Worked example (Bhandari Ex. 4.5)

Example 4.5 (). Design a knuckle joint for 50 kN. 30C8 (Syt = 400), Syc = Syt, (fs) = 5, Ssy = 0.5Syt.
  1. σt = σc = σb = 80, τ = 40 N/mm².
  2. \(D = \sqrt{4(50\,000)/\pi(80)} = 28.2\), so 30 mm. D₁ = 33, so 35 mm. a = 0.75D = 22.5 → 25 mm; b = 1.25D = 37.5 → 40 mm.
  3. Pin by shear: \(d = \sqrt{2P/\pi\tau} = 28.2\). Pin by bending: \(d^3 = \frac{32}{\pi(80)}\cdot25\,000\left[\frac{40}{4}+\frac{25}{3}\right]\Rightarrow d = 38.8\). Bending governs, so d = 40 mm.
  4. d₀ = 2d = 80 mm, d₁ = 1.5d = 60 mm.
  5. Eye: σt = P/b(d₀−d) = 31.25, σc = P/bd = 31.25, τ = 31.25. All OK.
  6. Fork: σt = P/2a(d₀−d) = 25, σc = P/2ad = 25, τ = 25. All OK.

Notice that bending, not shear, set the pin size. Questions that ask for the pin "by shear" alone are incomplete. Write both.

4. Practice: Tutorial Q6 (knuckle part)

Tutorial Q6 ()Knuckle joint for 65 kN, 40C8 (Syt = 460), (fs) = 4, distortion energy theory; bending and crushing 30% above tensile. So σt = 115, σb = σc = 149.5, τ = 66.36 N/mm². Use D = 28 mm, a = 21 mm, b = 35 mm.

(a) Pin diameter from double shear.

\(d = \sqrt{2(65\,000)/\pi(66.36)} = 24.97\) mm.

(b) Pin diameter from bending.

\(d^3 = \frac{32}{\pi(149.5)}\cdot32\,500\left[\frac{35}{4}+\frac{21}{3}\right] = 34\,880\Rightarrow d = 32.67\). Bending governs, so take d = 35 mm, d₀ = 70 mm, d₁ = 52.5 mm.

(c) Check: tensile stress in the eye with d = 35, d₀ = 70, b = 35.

\(P/b(d_0 - d) = 65\,000/(35\times35) = 53.1 < 115\) ✓. Crushing in the eye is also 53.1 < 149.5 ✓; shear in the eye 53.1 < 66.36 ✓. Fork: 65 000/(2·21·35) = 44.2 for tension, crushing and shear, all OK.

Why is the load on the pin taken as triangular in the fork but uniform in the eye?

  1. The fork is always made of a weaker material
  2. The fork prongs deflect, so pressure peaks inside
  3. The eye is longer, so the load spreads evenly
  4. Bhandari assumes it only to simplify the algebra
A loose pin bends. Pressure in each fork prong is highest at the inner edge, next to the eye, and falls towards the outside, so it is modelled as triangular, acting at a/3 from the inner face (Fig. 4.22).

In which application would you use a knuckle joint rather than a cotter joint?

  1. Piston rod to crosshead of a steam engine
  2. Foundation bolt holding a machine to its base
  3. Connecting two rotating shafts carrying torque
  4. Tie bars of a roof truss needing small rotation
A knuckle joint allows angular movement about the pin, which suits trusses, links and lever fulcrums. The first two are classic cotter joints. Rotating shafts need couplings.

Exam traps

  • Designing the pin for shear only. Check bending, which usually governs.
  • Using 2a for the eye or b for the fork in the crushing check: the eye has thickness b, the fork has two prongs of a.
  • Forgetting that d₀ − d is the net width at the pin hole.
