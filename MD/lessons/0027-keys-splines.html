1. Types of key and where each is used

A key connects a shaft to a hub (pulley, gear, sprocket) to transmit torque and prevent relative rotation. Most keys also stop axial sliding; feather keys and splines don't. Material: steel with Sut ≥ 600 N/mm² (45C8, 50C8) ().

2. Derivation: stresses in a flat key

Derive Bhandari Eqs 9.27–9.29 for a key of width b, height h and length l on a shaft of diameter d carrying torque Mt.
  1. Assume the force on the key acts tangentially at the shaft surface: \(P = \dfrac{M_t}{d/2} = \dfrac{2M_t}{d}\).
  2. Shear across the plane at the shaft surface, area b·l: \(\tau = \dfrac{P}{bl} = \boxed{\dfrac{2M_t}{dbl}}\).
  3. Crushing on the side face; the key bears on about h/2 in the shaft (or hub), so the area is (h/2)·l: \(\sigma_c = \dfrac{P}{(h/2)l} = \boxed{\dfrac{4M_t}{dhl}}\).
  4. For a square key (h = b): \(\sigma_c = \dfrac{4M_t}{dbl} = 2\tau\). The crushing stress is twice the shear stress. Since Syc ≈ 2Ssy (MSST: Ssy = 0.5Syt, Syc = Syt), a square key is equally strong in shear and crushing. That's why Ex. 9.13 gives the same length both ways.

3. Derivation: why key length ≈ 1.5d

Derive the length of a square key (b = d/4) that is as strong in shear as the shaft is in torsion (same material and allowable τ).
  1. Torque the key can carry in shear: \(M_t = \tau\,b\,l\,\dfrac{d}{2}\).
  2. Torque the shaft can carry: \(M_t = \dfrac{\pi d^3}{16}\tau\).
  3. Equate: \(b\,l\,\dfrac{d}{2} = \dfrac{\pi d^3}{16}\Rightarrow l = \dfrac{\pi d^2}{8b}\).
  4. With b = d/4: \(l = \dfrac{\pi d}{2} = 1.571d\). Hence the industrial rule "l ≥ 1.5d" ().
Kennedy key (Eqs 9.30, 9.31), with each key carrying Mt/2 \[ \tau = \frac{M_t}{\sqrt2\,d\,b\,l} \qquad \sigma_c = \frac{\sqrt2\,M_t}{d\,b\,l} \]

The force on each key is P = (Mt/2)/(d/2) = Mt/d. The key sits at 45°: its shear plane (diagonal) is √2·b long, and its bearing face is b/√2 wide.

Straight splines (Eq. 9.32), with n splines, major D, minor d, hub length l, pressure pm (≤ 6.5 N/mm²) \[ M_t = p_m\cdot\underbrace{\tfrac12(D-d)\,l\,n}_{\text{area}}\cdot\underbrace{\tfrac{D+d}{4}}_{R_m} = \tfrac18\,p_m\,l\,n\,(D^2-d^2) \]

Force to slide the hub: friction μP with P = Mt/Rm.

4. Practice (Bhandari Examples)

Ex. 9.13 (): square key for a gear on a 25 mm shaft, 15 kW at 720 rpm, 50C4 (Syt = Syc = 460), (fs) = 3. With b = h = 6 mm, find the key length.

Mt = 198 944 N·mm; τ = 230/3 = 76.67, σc = 153.33. Shear: l = 2Mt/(τdb) = 34.6; crushing: l = 4Mt/(σcdh) = 34.6. Key 6 × 6 × 35 mm.

Ex. 9.14 (): flat key 16 × 10 on a 50 mm shaft, 475 N·m, Syt = Syc = 230, (fs) = 3. Length?

τ = 38.33 gives l = 30.98; σc = 76.67 gives l = 4(475 000)/(76.67 × 50 × 10) = 49.56. Crushing governs (a flat key is weaker in crushing), so 50 mm.

Ex. 9.15 (): Kennedy keys 10 × 10 on a 40 mm shaft, 35 kW at 300 rpm, 45C8 (Syt = Syc = 380), (fs) = 3, distortion energy theory. Required length?

Mt = 1 114 085; τ = 0.577(380)/3 = 73.09; σc = 126.67. Shear: l = Mt/(√2 dbτ) = 26.95; crushing: l = √2Mt/(dbσc) = 31.10 mm, which governs.

Ex. 9.17 (): splines 8 × 52 × 60, 20 kW at 300 rpm, pm = 6.5 N/mm², μ = 0.06. Hub length?

Mt = 636 620. l = 8Mt/(pm n (D² − d²)) = 8(636 620)/(6.5 × 8 × 896) = 109.3 → 110 mm. Shifting force: P = Mt/28 = 22 736 N, so μP = 1364 N.

Ex. 9.16 (): a Woodruff key (Ø20 disc, 6 mm thick, seated 4 mm off the centre line) on a 30 mm shaft, 5 kW at 300 rpm, Syc = 460. The key area in contact with the hub is 77.81 mm². Factor of safety against crushing?

P = Mt/15 = 159 155/15 = 10 610 N; σc = 10 610/77.81 = 136.4, so (fs) = 460/136.4 = 3.37. Shear on chord CD = 18.33 mm × 6 mm gives τ = 96.5 and (fs) = 0.577(460)/96.5 = 2.75.

5. GATE corner

For a square key transmitting torque, the ratio of crushing stress to shear stress is:

  1. 0.5, since crushing area is twice the shear area
  2. 2, since crushing area is half the shear area
  3. 1, since both act over the same key surface
  4. √2, since the key carries load at 45 degrees
Shear area = b·l; crushing area = (h/2)·l = (b/2)·l, so σc/τ = 2.

A square key of side d/4 is to be as strong in shear as the shaft is in torsion. Its length should be:

  1. d, equal to the shaft diameter
  2. πd/4, about 0.79 times the diameter
  3. 2d, twice the shaft diameter
  4. πd/2, about 1.57 times the diameter
l = πd²/(8b) = πd/2 with b = d/4 (derivation above).

Which connection lets a gear slide along its shaft while transmitting torque?

  1. A feather key or splines
  2. A gib-head taper key
  3. A Woodruff key
  4. A hollow saddle key
The feather key (fixed to one member, sliding fit in the other) and splines allow axial movement. Taper and Woodruff keys lock axially. A saddle key relies on friction ().

Exam traps

  • Using h instead of b in the shear equation. Shear uses width b; crushing uses h/2. (Bhandari's own Ex. 9.24 misprints this: the key shear there should be 2Mt/(dbl) = 73.7 N/mm², not 168.4.)
  • Forgetting that each Kennedy key takes half the torque.
  • Calling a saddle key "positive". It transmits by friction.
