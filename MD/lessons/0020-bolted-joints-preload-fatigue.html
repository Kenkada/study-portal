Bolt preload, joint stiffness and fluctuating load

About 25 minutes · Bhandari §7.17–7.18

Your win: you can work out how much of an external load a preloaded bolt actually feels, and size a bolt for fluctuating load using the Goodman line with Bhandari's load line.
Warm-up (Lessons 9, 18)
Goodman line equation?
Sm/Sut + Sa/Se = 1
Stiffness of a bar of area A, length l?
k = AE/l

1. Why preload helps

Tightening the nut stretches the bolt (preload Pi) and squeezes the clamped parts. When an external tension P is applied, the bolt stretches a little more and the parts unload by the same amount. So the bolt feels only a fraction of P ().

Eqs 7.20–7.26 \[ k_b = \frac{\frac{\pi}{4}d^2E_b}{l} \qquad k_c = \frac{A_cE_c}{l},\ A_c \approx \tfrac{\pi}{4}[(3d)^2 - d^2] = 2\pi d^2 \] \[ \Delta P = P\,\frac{k_b}{k_b + k_c} = C\,P \qquad P_b = P_i + CP \qquad \text{joint opens at } P = P_i\,\frac{k_b + k_c}{k_c} \]

Soft gasket (kc → 0): Pb = Pi + P, so the bolt feels the whole load. Hard joint (kc → ∞): Pb = Pi, the bolt feels none of it. Stiff joints protect the bolt.

2. Fluctuating external load (0 → P)

Bhandari's load line (Kimmelmann line) and Eq. 7.30 \[ \sigma_m = \frac{P_i}{A} + \frac{CP}{2A} \qquad \sigma_a = \frac{CP}{2A} \qquad \Rightarrow\ \sigma_m = \frac{P_i}{A} + \sigma_a\ \text{(45° line from } P_i/A) \] \[ S_a = \frac{S_{ut} - P_i/A}{1 + S_{ut}/S_e} \qquad \sigma_a = \frac{P_a}{A} = \frac{S_a}{(fs)} \]

For threaded parts: Ka is built into Kf (rolled threads 2.2 for grades 3.6–5.8 and 3.0 for 6.6–10.9; cut threads 2.8 and 3.8; fillet 2.1–2.3). Kb = 1 (axial). Assume 90% reliability ().

Why connecting-rod bolts are preloaded close to yield: with kc = 10kb, the bolt sees only P/22 as fluctuation, so the load is almost static and the bolt can be designed on static strength ().

3. Worked example (Bhandari Ex. 7.18)

Example 7.18 (). Two aluminium plates (E = 71 000; plate area 2.356d², grip 50 mm) are clamped by a 45C8 bolt (Sut = 630, E = 207 000). Preload 5 kN; external load 0 → 10 kN; Kf = 2.2; 90% reliability; (fs) = 2. Find the bolt size.
  1. Se = KbKcKdS′e = (1)(0.897)(1/2.2)(315) = 128.4 N/mm².
  2. kb = 3251.6d², kc = 3345.5d², so C = 0.4929.
  3. Pmax = 5000 + 0.4929(10 000) = 9929 N, Pmin = 5000 N, so Pa = 2464.5 N.
  4. \(S_a = \dfrac{630 - 5000/A}{1 + 630/128.4} = \dfrac{630 - 5000/A}{5.9}\).
  5. \(\dfrac{2464.5}{A} = \dfrac{S_a}{2}\Rightarrow A = 54.1\) mm², so M10 × 1.25 (At = 61.2 mm²).

4. Practice (Bhandari Examples)

Ex. 7.16 (): the same joint as Ex. 7.18 but with a static external load of 10 kN and preload 5 kN. Find the resultant bolt load Pb.

ΔP = 10 000 × 0.4929 = 4929 N. Pb = 5000 + 4929 = 9929 N. With σt = 380/2.5 = 152: A = 65.3 mm², so M12 (84.3).

Ex. 7.17 (): preload 2.5 kN, external load 5 kN, kc = 2.5kb, 30C8 (Syt = 400), (fs) = 2.5. Required stress area?

ΔP = 5000/(1 + 2.5) = 1428.6. Pb = 3928.6 N. A = 3928.6/160 = 24.55 mm², so M8 (36.6).

Ex. 7.19 (): load 0 → 10 kN, kc = 3kb. Preload is set so the joint is just about to open at 50% overload. 50C4 (Sut = 660), Kf = 2.2, 90% reliability, (fs) = 2. Required area?

Opening at 15 kN: Pi = 15 000 × 3/4 = 11 250 N. C = 0.25, so Pa = 1250 N. Se = 0.897(330)/2.2 = 134.5.

\(\frac{1250}{A} = \frac{660 - 11\,250/A}{2(1 + 660/134.5)}\Rightarrow A = 39.4\) mm², so M8 × 1 (39.2).

To make a bolt feel less of a fluctuating external load, the designer should:

  1. Make the clamped parts stiff relative to the bolt
  2. Use a soft gasket between the clamped parts
  3. Reduce the preload in the bolt to zero
  4. Use a shorter, stiffer bolt with fine threads
C = kb/(kb + kc): a large kc (stiff parts, hard gasket) or a small kb (long, slender, uniform-strength bolt) makes C small.

In Bhandari's fatigue diagram for a preloaded bolt, the load line starts at:

  1. The origin, at 45°, like a repeated stress
  2. Se on the σa axis, going downward
  3. Pi/A on the σm axis, at 45°
  4. Syt on the σm axis, going upward
σm = Pi/A + σa is a 45° line through (Pi/A, 0), the Kimmelmann line (Fig. 7.37).

Exam traps

  • Adding the whole external load to the preload. Only CP is added.
  • Applying Ka and Kb = 0.85 to a bolt. For threads, Ka is inside Kf and Kb = 1.
