Warm-up (Unit 1)
Permissible shear stress by DET from Syt and (fs)?
\(\tau = 0.577S_{yt}/(fs)\). By MSST it is \(0.5S_{yt}/(fs)\).
Stress on a pin pressed against a hole: which area?
The projected area, length × diameter.

1. What it is and where it's used

A cotter joint connects two co-axial rods carrying axial tension or compression, never rotating shafts that transmit torque. Examples: piston rod to crosshead, valve spindle to fork, pump rod joints, foundation bolts (). A tapered steel wedge, the cotter, passes through slots in the socket (on rod A) and the spigot (on rod B). Driving it in draws the rods together. The taper (1 in 24 to 1 in 32, on one side only) keeps it tight and makes it easy to knock out. Slot clearance is 1.5–3 mm.

Advantages: quick to assemble and dismantle, the wedge action gives a high tightening force, and it is simple to design and make.

2. Ten ways it can fail, ten equations

Assumptions: axial tension, stress concentration at the slots ignored, initial tightening stress ignored. A higher (fs) covers these (–90).

3. Worked example (Bhandari Ex. 4.2)

Example 4.2 (). Design a cotter joint for 50 kN axial tension. Material 30C8 (Syt = 400). (fs) = 6 for rods, socket and spigot; 4 for the cotter. Syc = 2Syt, Ssy = 0.5Syt.
  1. Permissible stresses. Rods/ends: σt = 66.67, σc = 133.33, τ = 33.33. Cotter: σt = σb = 100, τ = 50 N/mm².
  2. Rod: \(d = \sqrt{4P/\pi\sigma_t} = 30.9\), so 32 mm. Cotter thickness: t = 0.31(32) = 9.92, so 10 mm.
  3. Spigot: \(\frac{\pi}{4}d_2^2 - 10d_2 = 750 \Rightarrow d_2 = 37.9\), so 40 mm.
  4. Socket: \(\frac{\pi}{4}(d_1^2 - 40^2) - 10(d_1 - 40) = 750 \Rightarrow d_1 = 52.0\), so 55 mm.
  5. Collars and ends: d₃ = 1.5d = 48, d₄ = 2.4d = 76.8 → 80, a = c = 0.75d = 24 mm.
  6. Cotter width: shear \(b = P/2t\tau = 50\) mm; bending \(b^2 = \frac{3P}{t\sigma_b}\left[\frac{40}{4} + \frac{80-40}{6}\right] \Rightarrow b = 50\) mm. So b = 50 mm.
  7. Checks: spigot crushing \(P/td_2 = 125 < 133.3\) ✓; spigot shear \(P/2ad_2 = 26.0 < 33.3\) ✓; socket crushing \(P/(d_4-d_2)t = 125\) ✓; socket shear 26.0 ✓. t₁ = 0.45d = 15 mm.

4. Practice: Tutorial sheet 2, Q6 (cotter part)

Tutorial Q6 ()Design a socket-and-spigot cotter joint for 65 kN. Material 40C8, Syt = 460 N/mm², (fs) = 4, distortion energy theory. Bending and crushing stresses may be 30% more than tensile. So σt = 115, σc = σb = 149.5, τ = 0.577(115) = 66.36 N/mm².

(a) Rod diameter before rounding.

\(d = \sqrt{4(65\,000)/\pi(115)} = 26.83\), so 28 mm.

(b) With the empirical t = 0.31d ≈ 9 mm, tension in the spigot needs d₂ = 33.2 mm. What d₂ does spigot crushing demand?

\(d_2 = P/(t\sigma_c) = 65\,000/(9\times149.5) = 48.3\) mm. Far more than tension needs, so the design is unbalanced. The cure: thicken the cotter. With t = 12 mm, tension needs d₂ = 35.5 and crushing 36.2, so take d₂ = 38 mm and both checks pass (σt = 95.9, σc = 142.5).

(c) With t = 12 mm and d₂ = 38 mm, find the socket outer diameter d₁ from socket tension.

\(\frac{\pi}{4}(d_1^2 - 38^2) - 12(d_1 - 38) = 565.2 \Rightarrow 0.7854d_1^2 - 12d_1 - 1243.3 = 0 \Rightarrow d_1 = 48.15\), so 50 mm.

(d) Socket collar diameter d₄ from crushing of the socket end.

\(d_4 = d_2 + P/(t\sigma_c) = 38 + 36.2 = 74.2\), so 75 mm (larger than the empirical 2.4d = 67 mm).

(e) Cotter width b: the larger of shear and bending (t = 12, d₂ = 38, d₄ = 75).

Shear: \(b = 65\,000/(2\times12\times66.36) = 40.8\). Bending: \(b^2 = \frac{3(65\,000)}{12(149.5)}\left[\frac{38}{4}+\frac{37}{6}\right] = 1703 \Rightarrow b = 41.3\). So b = 42 mm.

Remaining: a = c = 0.75d = 21 mm (shear needs only about 13); d₃ from collar crushing \(= \sqrt{38^2 + 4P/\pi\sigma_c} = 44.7\), so 45 mm; t₁ = 0.45d = 12.6, so 13 mm.

Why is the cotter tapered on one side only?

  1. A double taper would weaken the cotter in shear
  2. Tapering both sides prevents the joint from tightening
  3. One taper is easier to machine and gives no loss
  4. One taper lets the cotter carry the bending load
Machining a taper on two sides is harder and offers no specific advantage ().

Which area resists crushing of the spigot end?

  1. t × d₂, cotter thickness times spigot diameter
  2. a × d₂, spigot end length times spigot diameter
  3. b × t, cotter width times cotter thickness
  4. π d₂²/4, full cross-section of the spigot end
The cotter bears on a narrow rectangle t wide and d₂ long (Eq. 4.25h). a × d₂ is a shear area (two of them).

Can a cotter joint connect two rotating shafts that transmit torque?

  1. Yes, if the cotter is designed for torsional shear
  2. Yes, when the shafts run at low speed only
  3. No, because the taper loosens at high speed
  4. No, it is meant only for axial force
Bhandari: "It is not used for connecting shafts that rotate and transmit torque." Use a coupling for that (Lessons 28–29).

Exam traps

  • Spigot tension area: don't forget to subtract the slot (d₂t).
  • Calculating b from shear only. Always check bending too.
  • Skipping the crushing checks. In Tut Q6 they govern.
  • Not drawing the dimensioned sketch. Design questions expect one (Bhandari Fig. 4.17).
