Power transmission elements: formula and procedure sheet

Bhandari notation; N, mm, N/mm² unless stated. Prints on 3 pages.

Shafts (Ch. 9)

Strength

\[ \tfrac{16}{\pi d^3}\sqrt{M_b^2+M_t^2}=\tfrac{0.5S_{yt}}{(fs)}\ \ (T_e=\sqrt{M_b^2+M_t^2}) \] \[ \tfrac{16}{\pi d^3}\big[M_b+\sqrt{M_b^2+M_t^2}\big]=\tfrac{S_{yt}}{(fs)}\ \ (M_e=\tfrac12[\,\cdot\,]) \]

Hollow: d³ → do³(1 − k⁴). Equal-weight strength ratio (1 + k²)/√(1 − k²).

ASME code

\[ \tfrac{16}{\pi d^3}\sqrt{(k_bM_b)^2+(k_tM_t)^2}=\tau_{max} \]

τmax = min(0.30Syt, 0.18Sut), × 0.75 with keyway. kb/kt: gradual 1.5/1.0; minor shock 1.5–2/1–1.5; heavy shock 2–3/1.5–3.

Rigidity and loads

θ° = 584Mtl/(Gd⁴) [hollow: d⁴(1 − k⁴)]; 0.25°/m machine tools, 3°/m line shafts; G = 79 300. Pulley: Mt = (P₁ − P₂)R, pull P₁ + P₂ (+ weight). Gear: Pt = 2Mt/d′, Pr = Pt tan α. M = √(MV² + MH²).

Keys, splines, couplings

Keys

τ = 2Mt/(dbl), σc = 4Mt/(dhl); square key σc = 2τ. Square b = h = d/4, l ≥ 1.5d (equal-strength l = πd²/8b = 1.571d). Flat b = d/4, h = d/6. Kennedy: τ = Mt/(√2 dbl), σc = √2Mt/(dbl). Splines: Mt = pmln(D² − d²)/8, pm ≤ 6.5; shift force μMt/Rm.

Muff and clamp

Muff: D = 2d + 13, L = 3.5d, sleeve τ = 16MtD/π(D⁴ − d⁴), key length L/2. Clamp: D = 2.5d, L = 3.5d, P₁ = 2Mt/(fdn) (f ≈ 0.3), P₁ = πd₁²σt/4; empirical d₁ = 0.2d + 10 (d < 55), 0.15d + 15.

Flange couplings

dh = 2d, lh = 1.5d, D = 3d, t = 0.5d, t₁ = 0.25d, dr = 1.5d, D₀ = 4d + 2t₁; N = 3/4/6. Fitted bolts τ = 8Mt/(πDNd₁²), σc = 2Mt/(Nd₁tD). Clearance bolts Mt = μPiNRf. Hub τ = 16Mtdh/π(dh⁴ − d⁴); flange τ = 2Mt/(πdh²t).

Bushed-pin flexible

D = 3d–4d; d₁ = 0.5d/√N; Db² = 2Mt/(DN) (pm = 1, lb = Db); pin τ = 8Mt/(πd₁²DN) ≤ 35; pin bending M = P(gap + lb/2), P = 2Mt/(DN), which usually governs.

Belts (Ch. 13)

Geometry

Open: αs = 180° − 2 sin⁻¹[(D − d)/2C]; L = 2C + π(D + d)/2 + (D − d)²/4C. Crossed: sin β = (D + d)/2C, L with (D + d)². C ≈ D + 1.5d (i < 3), D (i > 3).

Tensions and power

\[ \tfrac{P_1-mv^2}{P_2-mv^2}=e^{f\alpha}\ \ (\text{V: } e^{f\alpha/\sin(\theta/2)}) \]

kW = (P₁ − P₂)v/1000; Pc = mv²; Pi = (P₁ + P₂)/2; max power at v = √(Pmax/3m) (Pmax = 3Pc, P₁ = 2Pc). V-belt 40°: μeff = 2.92μ.

Selection

Flat (Dunlop): v 17.8–22.9 m/s; corrected kW = FaFdP; rating 0.0118 (HI-SPEED) or 0.0147 (FORT) × v/5.08 kW per mm per ply. V-belt: belts = PFa/(PrFcFd); recompute C after choosing standard Lp. Pulley arms (elliptical, half loaded): a = 1.72∛(Mt/(Nσb)).

Chains (Ch. 14)

D = p/sin(180°/z); v = zpn/60 000; i = z₂/z₁; Δv/v = 1 − cos(180°/z) (z₁ ≥ 17, preferably 19–21, odd). Ln = 2a/p + (z₁ + z₂)/2 + [(z₂ − z₁)/2π]²p/a, rounded even; a = (p/4)[m + √(m² − 8((z₂ − z₁)/2π)²)], m = Ln − (z₁ + z₂)/2, then × 0.998. Required rating = kW·Ks/(K₁K₂). a = 30p–50p; wrap ≥ 120°; tight side on top.

Clutches (Ch. 11)

Plate

Uniform pressure: P = πp(D² − d²)/4, M = μPz(D³ − d³)/[3(D² − d²)]. Uniform wear: P = πpad(D − d)/2, M = μPz(D + d)/4 (design basis). Optimum d/D = 0.577. Pairs z = n − 1.

Cone and centrifugal

Cone: M = μP(D + d)/(4 sin α), b = (D − d)/(2 sin α), α ≈ 12.5°. Centrifugal: Ps = mω₁²rg/1000; M = μmrgrdz(ω₂² − ω₁²)/1000.

Energy and heat

t₁ = Δω I₁I₂/[(I₁ + I₂)Mt]; E = ½[I₁I₂/(I₁ + I₂)]Δω²; Δt = E/(mc), c ≈ 500 J/kg°C.

Brakes (Ch. 12)

Energy and block

E = ½m(v₁² − v₂²) + ½I(ω₁² − ω₂²) + mgh = Mtθ. Short shoe: Mt = μNR; P = N(a ∓ μc)/b; self-locking a ≤ μc. Long shoe μ′ = 4μ sin θ/(2θ + sin 2θ). Pivoted: h = 4R sin θ/(2θ + sin 2θ), M = 2μR²wpmax sin θ.

Internal expanding

p = pmax sin φ/sin φmax; Mn = [pmaxRwh/(4 sin φmax)][2(θ₂ − θ₁) − (sin 2θ₂ − sin 2θ₁)]; Mf = [μpmaxRw/(4 sin φmax)][4R(cos θ₁ − cos θ₂) − h(cos 2θ₁ − cos 2θ₂)]; Mt = μR²pmaxw(cos θ₁ − cos θ₂)/sin φmax; P = (Mn ∓ Mf)/C (leading −).

Band and disc

P₁/P₂ = eμθ; M = (P₁ − P₂)R; pmax = P₁/(Rw); differential: P = (P₂a − P₁b)/l, self-locking a ≤ beμθ. Disc: Rf = (2/3)(Ro³ − Ri³)/(Ro² − Ri²), M = μPRf per pad, A = ½θ(Ro² − Ri²). Δt = E/mc; pv limits 115 / 175 / 125.
