Cotter joint (§4.9–4.10)

Failure equations

Rod \(P=\frac{\pi}{4}d^2\sigma_t\) · spigot \(P=[\frac{\pi}{4}d_2^2-d_2t]\sigma_t\) · socket \(P=[\frac{\pi}{4}(d_1^2-d_2^2)-(d_1-d_2)t]\sigma_t\) · cotter shear \(P=2bt\tau\) · spigot shear \(P=2ad_2\tau\) · socket shear \(P=2(d_4-d_2)c\tau\) · crushing \(P=td_2\sigma_c\), \(P=(d_4-d_2)t\sigma_c\) · collar \(P=\frac{\pi}{4}(d_3^2-d_2^2)\sigma_c\), \(P=\pi d_2t_1\tau\)

\[ \text{cotter bending: } \sigma_b=\frac{(P/2)[d_2/4+(d_4-d_2)/6]}{tb^2/6} \]

Proportions

t = 0.31d · d₁ = 1.75d · d₂ = 1.21d · d₃ = 1.5d · d₄ = 2.4d · a = c = 0.75d · b = 1.6d · t₁ = 0.45d · taper 1 in 32 (1 in 24) · clearance 1.5–3 mm. Procedure: d → t → d₂ → d₁ → d₃, d₄ → a, c → b (max of shear, bending) → check crushing and shear.

Knuckle joint (§4.11–4.12)

Equations

Rod \(D=\sqrt{4P/\pi\sigma_t}\), D₁ = 1.1D · pin shear \(d=\sqrt{2P/\pi\tau}\) · pin bending \(\sigma_b=\frac{32(P/2)(b/4+a/3)}{\pi d^3}\) · eye: \(\sigma_t=\frac{P}{b(d_0-d)}\), \(\sigma_c=\frac{P}{bd}\), \(\tau=\frac{P}{b(d_0-d)}\) · fork: same with 2a in place of b.

Proportions

d = D · d₀ = 2d · d₁ = 1.5d · a = 0.75D · b = 1.25D · x ≈ 10 mm.

Riveted joints (§8.19–8.29)

Per pitch length

\[ P_s=n\tfrac{\pi}{4}d^2\tau\ (\times 2\text{ or }1.875\text{ double}),\ P_t=(p-d)t\sigma_t,\ P_c=ndt\sigma_c \] \[ \eta=\frac{\min(P_s,P_t,P_c)}{pt\sigma_t} \]

p ≈ 3d · m = 1.5d · pt = 0.8p (chain), 0.6p (zig-zag).

Boiler longitudinal joint

\(t=\frac{p_iD_i}{2\sigma_t\eta}+CA\) · \(d=6\sqrt t\) (t > 8) · \(p=\frac{(n_1+1.875n_2)\pi d^2\tau}{4t\sigma_t}+d\) with pmin = 2d, pmax = Ct + 41.28 · pt = 0.2p + 1.15d (outer), 0.165p + 0.67d · straps t₁ = 0.625t(p − d)/(p − 2d) (equal); 0.75t / 0.625t (unequal) · σt 80, τ 60, σc 120.

Eccentric rivet/bolt group (in plane)

\[ P'=\frac{P}{n},\quad P''_i=\frac{Pe\,r_i}{\sum r^2}\ (\perp r_i),\quad P_i=\vec P'+\vec P''_i \]

\(P=\sqrt{P'^2+P''^2+2P'P''\cos\theta}\); size: Pmax = (π/4)d²τ.

Welded joints (§8.1–8.17)

Direct load

Butt: P = σttlη · fillet throat t = 0.707h · parallel P = 0.707hlτ (1.414hlτ for two) · transverse P = 0.707hlσt · add 15 mm per weld · exact: τmax on 45° plane (parallel), on 67.5° plane = 1.21P/hl (transverse, 1.17× stronger) · angle: l₁y₁ = l₂y₂.

Eccentric / bending / torsion

In-plane: τ₁ = P/A, τ₂ = Mr/J, J = Σ A(l²/12 + r₁²), vector sum. Bending: τ₁ = P/A, σb = My/I, τmax = √((σb/2)² + τ₁²); two welds b at ±d/2: I = bd²t/2; circular: I = πtr³, J = 2πtr³; torsion τ = Mt/2πtr².

Fatigue (Jennings Kf)

Reinforced butt 1.2 · toe of transverse fillet 1.5 · end of parallel fillet 2.7 · T-butt with sharp corner 2.0.

Bolted joints (Ch. 7)

Basic

σ = P/(πdc²/4) or P/At · dc ≈ 0.8d · nut h = 0.8d · tightening torque Mt ≈ 0.2Pid · uniform-strength hole d₁ = √(d² − dc²). M8 36.6 · M10 58 · M12 84.3 · M16 157 · M20 245 · M24 353 · M30 561 · M36 817 mm².

Eccentric (perpendicular to axis, tilting)

\[ P'=\frac{P}{n}\ \text{(shear)},\ P''_1=\frac{Pe\,l_1}{2(l_1^2+l_2^2+\dots)}\ \text{(tension)} \]

τmax = √((σ/2)² + τ²) = 0.5Syt/(fs). Circular base: \(P_{max}=\frac{2Pl(a+b)}{n(2a^2+b^2)}\) (slewing) or with b cos(180°/n) (fixed direction).

Preload and fatigue

kb = (π/4)d²E/l · Ac ≈ 2πd² · C = kb/(kb + kc) · Pb = Pi + CP · opens at P = Pi(kb + kc)/kc · \(S_a=\frac{S_{ut}-P_i/A}{1+S_{ut}/S_e}\), σa = Sa/(fs) · threads: Kf 2.2–3.8, Kb = 1, 90% reliability.

Levers (§4.19–4.20)

Fl₂ = Pl₁ · bell crank R = √(F² + P² − 2FP cos θ) · arm: σb = M(d/2)/(bd³/12), d = 2b–3b · pin: R = p·d₁l₁ (p = 5–10 for a bronze bush; l₁/d₁ = 1–2) then check shear R/(2·πd₁²/4) · boss OD = 2d₁ · check the section through the pin hole.

Power screws (Ch. 6)

Geometry and torque

dc = d − p · dm = d − 0.5p · l = (starts)p · tan α = l/πdm · μ = tan φ.

\[ M_t=\tfrac{Wd_m}{2}\tan(\phi\pm\alpha)\ \ (+\text{ raise},\ -\text{ lower}) \]

Trapezoidal/Acme: μ → μ sec θ (θ = 15°/14.5°). Collar (uniform wear): (Mt)c = μcW(Do + Di)/4 = μcWRm.

Efficiency and self-locking

\[ \eta=\frac{\tan\alpha}{\tan(\phi+\alpha)},\ \ \eta_o=\frac{Wl}{2\pi(M_t)_t},\ \ \eta_{max}=\frac{1-\sin\phi}{1+\sin\phi}\ \text{at}\ \alpha=45°-\tfrac{\phi}{2} \]

Self-locking: φ ≥ α (μ ≥ tan α), so η < 50%. Differential screw: advance p₁ − p₂; compound: p₁ + p₂.

Screw and nut design

σc = W/(πdc²/4) · τ = 16Mt/πdc³ · τmax = √((σ/2)² + τ²) · thread shear τs = W/πdctz, τn = W/πdtz (t = p/2) · bearing Sb = 4W/πz(d² − dc²) · H = zp · Sb: jack steel/bronze 11–17, steel/CI 13–17; hoist 4–10; lead screw 1–1.5 · buckling: Johnson (short), Euler (long), n = 0.25 for fixed-free · hand force about 400 N (two workers 0.9 × 2 × 400).
