Springs and gears: formula and procedure sheet

Bhandari notation; N, mm, N/mm² unless stated. Prints on 3 pages.

Helical springs (Ch. 10)

Stress and deflection

\[ \tau = K\frac{8PD}{\pi d^3} = K\frac{8PC}{\pi d^2},\quad K = \frac{4C-1}{4C-4} + \frac{0.615}{C},\quad K_s = 1 + \frac{0.5}{C} \] \[ \delta = \frac{8PD^3N}{Gd^4},\quad k = \frac{Gd^4}{8D^3N},\quad U = \tfrac12P\delta \]

C = D/d (4–12; 6–9 cyclic). K: C = 5 → 1.3105, 6 → 1.2525, 8 → 1.184. G = 81 370. Series 1/k = Σ1/ki; parallel k = Σki.

Lengths and design

Active coils: plain Nt, plain + ground Nt − ½, square (ground) Nt − 2, extension Nt. Solid = Ntd; free = solid + (Nt − 1)(0.5–2 mm) or 15% δ + δmax; pitch = free/(Nt − 1). Buckling: free/D ≤ 2.6, else guide. τ = 0.3Sut (fs 1.5) to 0.5Sut (IS 4454). Sut falls with d, so trial and error. Range of force: d from Pmax, N from ΔP/Δδ.

Fluctuating load

\[ \tau_m = K_s\frac{8P_mD}{\pi d^3},\ \ \tau_a = K\frac{8P_aD}{\pi d^3},\ \ \frac{\tau_a}{S_{sy}/(fs) - \tau_m} = \frac{\tfrac12S'_{se}}{S_{sy} - \tfrac12S'_{se}} \]

Patented: S′se = 0.21Sut, Ssy = 0.42Sut. Oil-hardened: 0.22 and 0.45. Min-weight valve spring: Pmin = ½Pmax. Surge: f = ½√(k/m) (both ends on plates), keep f ≥ 15–20 × forcing.

Concentric springs

Same material, stress, free and solid length: C₁ = C₂, P₁/P₂ = d₁²/d₂², and with 2c = d₁ − d₂, d₁/d₂ = C/(C − 2). Opposite hands. Otherwise: parallel springs, equal δ (Ex. 10.18), or a stepped rate if free lengths differ (Ex. 10.19).

Open-coiled, torsion and leaf springs

Open-coiled (helix angle α, n turns)

T = WR cos α, M = WR sin α, wire length 2πRn/cos α. τ = 16WR cos α/πd³, σb = 32WR sin α/πd³, τmax = 16WR/πd³, σ₁ = (16WR/πd³)(1 + sin α).

\[ \delta = \frac{8WD^3n}{d^4\cos\alpha}\Big(\frac{\cos^2\alpha}{G} + \frac{2\sin^2\alpha}{E}\Big),\quad \phi = \frac{16WD^2n\sin\alpha}{d^4}\Big(\frac1G - \frac2E\Big) \]

Helical torsion spring

σb = Ki·32Mb/πd³, Ki = (4C² − C − 1)/[4C(C − 1)], Ko = (4C² + C − 1)/[4C(C + 1)]. θ = 64MbDN/Ed⁴ rad; k = Ed⁴/64DN (N·mm/rad). The wire is in bending. Load it in the winding direction.

Multi-leaf spring (end load P, half-length L)

\[ \sigma_g = \frac{12PL}{(3n_f + 2n_g)bt^2},\ \ \sigma_f = \frac{18PL}{(3n_f + 2n_g)bt^2},\ \ \delta = \frac{12PL^3}{Ebt^3(3n_f + 2n_g)} \]

ng includes the master leaf. Nipped (equal stress): σ = 6PL/nbt², C = 2PL³/Enbt³, Pi = 2ngnfP/[n(3nf + 2ng)]. U-bolt band l: 2L = span − l (slides, Khurmi). Standard t: 5, 6, 6.5, 7, 7.5, 8, 9, 10, 11, 12, 14, 16. Standard b: 32 … 125.

Gear geometry (Ch. 17)

Module system

d′ = mz, p = πm, a = m(zp + zg)/2, i = zg/zp = np/ng. 20° full depth: ha = m, hf = 1.25m, c = 0.25m, tooth thickness 1.5708m, fillet 0.4m, da = m(z + 2), df = m(z − 2.5). 14.5° FD: hf 1.157m, c 0.157m. Stub: ha 0.8m, hf m. Modules (Choice 1): 1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 16, 20.

Rules of thumb

Law of gearing: ω₁/ω₂ = O₂P/O₁P. zmin = 2/sin²α: 32 (14.5°), 17 (20°), 14 (stub); use zp = 18–20. b = 8m–12m (start at 10m). Ratio ≤ 6:1 per pair; two stages i = √i′, three stages ∛i′. Contact ratio ≥ 1.2 (1.4–1.7). Internal gears: zg − zp ≥ 10 (20° FD). Idler: same ratio, direction changes.

Spur gear strength (Ch. 17)

Forces and Lewis

\[ M_t = \frac{60\times10^6\,\text{kW}}{2\pi n},\ P_t = \frac{2M_t}{d'},\ P_r = P_t\tan\alpha,\ S_b = mb\sigma_bY,\ \sigma_b = \frac{S_{ut}}{3} \]

Driver: Pt opposes rotation; driven: Pt follows rotation; Pr points to its own centre. Weaker gear: smaller σbY (same material, so the pinion). Y (20° FD): 18 → .308, 20 → .320, 25 → .340, 30 → .358, 40 → .389, 50 → .408.

Effective load

Cs = start/rated torque (Table 17.4). Cv = 3/(3 + v) (cut, v < 10), 6/(6 + v) (hobbed, v < 20), 5.6/(5.6 + √v) (precision). Peff = CsPt/Cv.

\[ P_d = \frac{21v(Ceb + P_t)}{21v + \sqrt{Ceb + P_t}},\quad P_{eff} = C_sP_t + P_d \]

C = 11 400 (steel/steel), 7900 (steel/CI), 5700 (CI/CI). e (μm) = A + Bφ, φ = m + 0.25√d′: Gr 4: 3.2 + 0.25φ; Gr 6: 8 + 0.63φ; Gr 8: 16 + 1.25φ.

Wear and module

\[ S_w = bQd_p'K,\ Q = \frac{2z_g}{z_g \pm z_p},\ K = 0.16\Big(\frac{\text{BHN}}{100}\Big)^2 \] \[ m = \Big[\frac{60\times10^6}{\pi}\cdot\frac{\text{kW}\,C_s\,(fs)}{z\,n\,C_v\,(b/m)\,\sigma_bY}\Big]^{1/3} \]

Design: Sb, Sw ≥ Peff(fs), with fs 1.5–2. Assume v = 5 m/s first.

Helical and bevel gears (Chs 18–19)

Helical (ψ 15–25°, αn = 20°)

mn = m cos ψ, pn = p cos ψ, pa = p/tan ψ, tan αn = tan α cos ψ, d = zmn/cos ψ, a = mn(z₁ + z₂)/2cos ψ, b ≥ πmn/sin ψ, z′ = z/cos³ψ. Pa = Pt tan ψ, Pr = Pt tan αn/cos ψ (thrust: driver, right hand for RH, fingers with rotation).

\[ S_b = m_nb\sigma_bY(z'),\quad S_w = \frac{bQd_pK}{\cos^2\psi},\quad C_v = \frac{5.6}{5.6 + \sqrt v} \]

Pd = 21v(Ceb cos²ψ + Pt)cos ψ/[21v + √(Ceb cos²ψ + Pt)]. Herringbone: half power per half, ψ 20–45°. Crossed: Σ = ψ₁ ± ψ₂.

Bevel (90° shafts)

tan γ = zp/zg, γ + Γ = 90°, A₀ = √((Dp/2)² + (Dg/2)²), z′ = z/cos γ (Tredgold, back cone). Forces at rm = Dp/2 − (b sin γ)/2: Pt = Mt/rm, Pr = Pt tan α cos γ, Pa = Pt tan α sin γ. Gear radial = pinion axial.

\[ S_b = mb\sigma_bY\Big(1 - \frac{b}{A_0}\Big),\quad S_w = \frac{0.75bQD_pK}{\cos\gamma},\quad Q = \frac{2z_g}{z_g + z_p\tan\gamma} \]

Compare with Pt = 2Mt/Dp (large end). b = min(10m, A₀/3). Error e (Table 19.1): Class 3 = 0.0125 mm (m ≤ 5).
